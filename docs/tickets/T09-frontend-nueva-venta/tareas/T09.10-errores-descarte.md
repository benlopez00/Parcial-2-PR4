# T09.10 — Conservar el borrador frente a errores

- Responsable: Pablo.
- Rama: `ramaPablo`.
- Ticket padre: [T09](../ticket.md).
- Estado: Completado.

## Trabajo

Detallar faltantes, rechazos y sesión vencida; pedir confirmación de descarte y no reintentar una respuesta incierta.

## Criterio de aceptación

Un error no pierde ítems; un fallo de red no emite automáticamente otra factura.

## Evidencia

Ver [plan técnico](../plan.md) e [informe de auditoría](../informe-auditoria.md). Las pruebas de navegador usan una base temporal, no la base de trabajo del usuario.

## Revisión posterior

Los errores 5xx también se consideran resultado incierto: se comprobó una factura guardada seguida de una respuesta 500. La pantalla conserva el borrador y no habilita repetirla.
