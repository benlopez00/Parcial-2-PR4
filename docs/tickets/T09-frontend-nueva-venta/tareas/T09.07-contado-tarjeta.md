# T09.07 — Cobrar con contado o tarjeta

- Responsable: Pablo.
- Rama: `ramaPablo`.
- Ticket padre: [T09](../ticket.md).
- Estado: Completado.

## Trabajo

Monto automático o manual y vuelto; tarjeta con tipo, marca y últimos cuatro dígitos.

## Criterio de aceptación

Formato inválido bloquea contado; tarjeta conserva ceros y no solicita el número completo.

## Evidencia

Ver [plan técnico](../plan.md) e [informe de auditoría](../informe-auditoria.md). Las pruebas de navegador usan una base temporal, no la base de trabajo del usuario.
